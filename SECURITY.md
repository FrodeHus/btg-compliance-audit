# Security policy

## Reporting a vulnerability

Please report security issues privately and responsibly.

Use one of the following methods:

- GitHub Security Advisories for this repository, if enabled
- A private report through the repository maintainers' preferred contact channel

Do not open a public GitHub issue for a suspected security vulnerability.

## What to include

When reporting a vulnerability, please include:

- A clear description of the issue
- Affected version or branch
- Reproduction steps or proof of concept
- Impact and risk assessment
- Any suggested mitigation or workaround

## Response expectations

We aim to acknowledge valid reports within 5 business days and to work toward a fix as quickly as possible. We may ask for additional information while we investigate.

## Responsible disclosure

Please give maintainers time to investigate and remediate before public disclosure.

This project is security-sensitive because it audits emergency access controls and tenant-level Azure Entra configuration, so handling disclosures privately is important.
